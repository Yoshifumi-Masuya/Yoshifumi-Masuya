## Projects

### Steep Slope Warning Area Segmentation

数値標高データから作成した傾斜量図を入力として，急傾斜地崩壊危険区域を画素単位で予測するセマンティックセグメンテーションに取り組みました．U-Net，U-Net++，DeepLab v3，SegFormer，PSPNetなど複数のモデルを比較し，F値を用いて性能を評価しました．

Tech Stack: Python, PyTorch, OpenCV, scikit-learn, Matplotlib, NumPy, pandas
Keywords: Deep Learning，Semantic Segmentation
